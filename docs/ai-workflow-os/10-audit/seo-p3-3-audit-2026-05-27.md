## Findings

### Keep

- `@repo/seo` package boundary.
- `createMetadata` helper.
- `JsonLd` component.
- `schema-dts` type exports.
- Required `description` field.

### Refactor

- Replace stale next-forge/Vercel defaults with Jeriko defaults.
- Remove direct `process.env` access from the package.
- Replace `lodash.merge` with explicit composition and remove the dependency.
- Add package-local tests.
- Fix the contact page to pass a real description.

### Delete

- Direct `lodash.merge` dependency.
- Direct `@types/lodash.merge` dev dependency.

### Defer

- Locale-specific Open Graph locale handling.
- Canonical URL/base URL helper shared with sitemap/robots.
- CMS-driven metadata rendering.
- Web contact form Calendar type issue; this is not SEO-owned.
