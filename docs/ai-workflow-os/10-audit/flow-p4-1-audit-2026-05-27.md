## Findings

### Keep

- One `@repo/flow` package with subpath exports.
- Provider-neutral package boundary.
- Zod schemas as the post-parse contract layer.
- Runtime/event/trigger/cancellation contracts from the previous pass.
- Dependency-cruiser guard blocking provider SDKs and app imports.

### Refactor

- Replace the unimplemented parser only after a `.flow` grammar doc and token/CST contracts exist.
- Add source-language contracts before parser implementation:
  - token kinds;
  - indentation events;
  - comments;
  - scalar/block text;
  - CST nodes with source spans;
  - parser diagnostics.
- Add a parser fixture corpus before broad parser behavior.

### Delete / Avoid

- Do not add `yaml`.
- Do not implement a YAML-backed parser.
- Do not use wording that makes `.flow` a YAML dialect.

### Defer

- Full parser.
- Formatter.
- LSP/autocomplete.
- Expression language parser.
- Semantic graph / ASG.
- Runtime interpreter.
- Provider adapters.
- Database persistence and migration schema.
