# Product Brief

## Core Thesis

AI Workflow OS is a prompt-to-workflow platform. A user describes work, the main AI creates a persistent `.flow` operating file, and a durable runtime executes scoped tasks with tools, approvals, artifacts, issue cards, and reflection packets.

This is not a Manus clone, visual node builder, generic chatbot, or single long-running agent loop. The workflow file and runtime contract are the product.

## Product Primitive

User prompt to hidden `.flow` to validated AST/runtime JSON to durable run to artifacts, events, approvals, reports, and patches.

## Initial Users

- Founders and solo operators
- Agencies
- Solo developers
- SMB teams
- Operations-heavy teams that need recurring work without building node graphs

## Best Early Workflows

- Social/content operations
- Inbox drafting
- Lead generation and enrichment
- Competitor monitoring
- Weekly reports
- Inventory/email/CRM operations

## MVP Scope

- Prompt-to-workflow compiler
- Workflow preview
- `.flow` kernel and validator
- Generic executor
- AI task, sandbox command, mock tool call, human review
- Event log and live timeline
- Artifacts
- Issue cards
- Reflection packet
- One proof workflow: social content operator

## MVP Non-Goals

- Public marketplace
- Enterprise SSO
- Arbitrary public scripts
- Fully autonomous external send/post/update by default
- Visual node builder as the primary surface
- Live orchestration mode before kernel validation
