## Decision Rule

Imported decisions are accepted concept defaults, not final implementation proof. A decision can stay accepted only after codebase audit and primary-source research confirm that it still fits this repo.

Before changing package-specific architecture or APIs, verify the latest official docs and installed/latest package versions, inspect current local usage, then implement. No package refactor should rely on memory alone.

## Required Record Shape

Each future decision should include:

- Status
- Context
- Decision
- Consequences
- Alternatives considered
- Evidence
- Impacted files/packages
- Validation checklist
