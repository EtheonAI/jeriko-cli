# Design Direction

## Desired Feel

The interface should keep the clean Manus-like restraint while moving toward a more material, operational workflow console. It should feel calm, dense, and useful, not like a marketing dashboard or decorative agent toy.

## Product Layout Bias

- Left navigation for core areas.
- Center chat/control surface.
- Right live workflow panel.
- Compact top version bar for active workflow version, dry run, diff, fork, share, and rollback.

## Visual Rules

- Material surfaces with subtle depth, not heavy glass or decorative gradients.
- Dense lists and timelines over large empty hero sections.
- Cards only for repeated objects, modals, and framed tools.
- Clear status colors for running, waiting, failed, degraded, succeeded, and approval needed.
- Icons for common actions.
- Stable dimensions for timelines, task rows, artifact previews, and buttons.

## Design Research Needed

- Manus visual language inventory from current screenshots and code.
- GitHub Actions run detail patterns.
- Linear/Jira issue card patterns for failures.
- Vercel dashboard patterns for deployments, logs, and usage.
- Material Design 3 state layers, elevation, and interaction rules.
